# Revenue & Cost of Sales ETL

Проект демонстрирует автоматизацию обработки учетных данных, выгруженных из 1С, с использованием Python (Pandas) и DuckDB SQL для подготовки аналитической отчетности по выручке и себестоимости.

## Основные возможности

- Загрузка и объединение текстовых выгрузок 1С;
- Очистка и преобразование данных;
- Обработка данных с использованием DuckDB SQL;
- Формирование аналитической таблицы по выручке и себестоимости;
- Экспорт результатов в Excel.

## Используемые технологии

**Python • Pandas • NumPy • DuckDB SQL • ETL • Excel**

## Практическое применение

Проект разработан на основе реального сценария автоматизации обработки учетных данных и подготовки финансовой аналитической отчетности. Исходные данные и пути к источникам обезличены для публичной публикации.

## Примеры этапов обработки данных

- Исходная выгрузка по себестоимости;
- Очистка и преобразование данных;
- Исходная выгрузка по выручке;
- Очистка данных по выручке;
- Итоговое объединение данных по выручке и себестоимости.
